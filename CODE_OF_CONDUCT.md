# Code of Conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
in spirit: be kind, be curious, criticize ideas not people, no harassment.

If something happens that's not in that spirit, open an issue or contact
the maintainer directly. Bad-faith participation is grounds for being
asked to leave.
